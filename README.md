# Bot Chat 🤖

Một ứng dụng chatbot đơn giản được xây dựng bằng Node.js

## Tính năng
- 💬 Chat với bot
- 🚀 Dễ dàng mở rộng
- ⚡ Nhanh chóng

## Yêu cầu
- Node.js 14+ 
- npm hoặc yarn

## Cài đặt

```bash
# Clone repository
git clone https://github.com/toan424680-pixel/bot-chat.git
cd bot-chat

# Cài đặt dependencies
npm install

# Tạo file .env
cp .env.example .env
```

## Chạy ứng dụng

```bash
npm start
```

Ung dụng sẽ chạy trên `http://localhost:3000`

## Project Structure

```
bot-chat/
├── src/
│   ├── index.js          # Entry point
│   ├── chatbot.js        # Chatbot logic
│   └── responses.js      # Chatbot responses
├── .env.example          # Environment variables template

```
